# buildings

Field-level coverage audit and legal classification only, no addresses or individual records. Licence room count is not bedroom count. Reported facility area is not verified exclusive area. Building-use/area/revenue linkage blocked without lawful exact linkage and current building ledger.

Repository JSON is the reproducible build input. Run `node scripts/build-data.mjs` then `node scripts/validate-data.mjs`. Missing numeric facts are null, never zero. See [data contract](../../../docs/data/CONTRACT.md), per-field dictionary and source catalog.
