# registry

467 current legal-dong codes. Code is a string. Registry counts refer to records, not properties, rooms or Airbnb listings. Status operating means recorded status01, not observed operation. Events are Jan01–Nov11; closed date unavailable in general-lodging source stays null.

Repository JSON is the reproducible build input. Run `node scripts/build-data.mjs` then `node scripts/validate-data.mjs`. Missing numeric facts are null, never zero. See [data contract](../../../docs/data/CONTRACT.md), per-field dictionary and source catalog.
