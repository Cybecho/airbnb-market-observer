# revenue

Source periods, units and model definitions are retained but proprietary values are withheld. District annual median, city monthly mean and bedroom annual median are different metrics. None is actual Airbnb revenue. No income-minus-rent claim.

Repository JSON is the reproducible build input. Run `node scripts/build-data.mjs` then `node scripts/validate-data.mjs`. Missing numeric facts are null, never zero. See [data contract](../../../docs/data/CONTRACT.md), per-field dictionary and source catalog.
