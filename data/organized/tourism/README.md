# tourism

Nationality support is evidence of an unsupported cross, not fabricated country KPI rows. residence-country-historical is older provisional survey residence-country, not nationality; superseded by final survey. Visitor summary is tourism destinations, not lodging destinations.

Repository JSON is the reproducible build input. Run `node scripts/build-data.mjs` then `node scripts/validate-data.mjs`. Missing numeric facts are null, never zero. See [data contract](../../../docs/data/CONTRACT.md), per-field dictionary and source catalog.
