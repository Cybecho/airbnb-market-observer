# population

427 admin-dong rows preserve original continuation presence/OD/registry fields. Presence estimates persons at 04h/14h, not paid nights. OD is repeat movements, not unique visitors. segment shares are fractions 0–1; percentages use pct. Purpose and transport denominators differ. Short-term foreigners sex/age are unavailable; known-sex/age segment is not the short-term subgroup.

Repository JSON is the reproducible build input. Run `node scripts/build-data.mjs` then `node scripts/validate-data.mjs`. Missing numeric facts are null, never zero. See [data contract](../../../docs/data/CONTRACT.md), per-field dictionary and source catalog.
