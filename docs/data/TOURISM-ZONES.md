### 63개 지구단위계획의 조건

- 45~46쪽: 총목록. 47쪽: 기본 9곳(명동관광특구, 북창, 테헤란로, 잠실광역중심제1지구, 여의도 금융중심, 영등포지역 부도심권, 마포지구, 용산, 왕십리 광역중심). 48~51쪽: 한시 54곳. **지구단위계획구역 안의 상업지역**이 대상이다. 한시 54곳은 2026-02-19부터 위 부칙 기한까지의 신청. 기본 9곳에는 이 54곳의 일몰을 붙이지 않으나 서울도심 상향 수치 자체는 이들 기본 구역에서도 한시일 수 있다. ‘영구 1.3배’가 아니다. 56~97쪽: 63개 결정도 전부, 경계의 금회 변경 없음. 63개마다 표·도면 쪽을 JSON으로 수록했다.
- 51~53쪽 및 조례 51조 2항 1호 다·사목: 대상은 **관광호텔업, 한국전통호텔업, 가족호텔업, 호스텔업**을 위한 건립. 일반숙박, 외국인관광 도시민박업, 한옥체험업, 임대 또는 플랫폼에 등록했다고 이 혜택을 주지 않는다. 상한용적률 = 허용용적률 + 법적용적률 × 완화 비율(최대 30%). 서울도심 여부, 2000-07-01 전후의 용도지역 결정·상향, 객실 비율, 해당 등급결정 대상의 3성급 이상 객실·부대시설 요건, 복합·증축 여부 등을 따진다. 도심 일반상업지역의 52쪽 표 예시는 한시 기한 내 상한 1,040%, 기한 후 780%이며, 한시 54곳 자체가 기한 후에도 적용된다는 뜻은 아니다.
- 다른 개별법으로 계획된 구역은 그 계획을 따른다. 역사자산 밀집·보전지역은 제외될 수 있고 둘 이상의 용도지역이 혼재된 노선형 상업지역은 제외된다. 특별계획(가능)구역은 세부개발계획 수립·변경 단계에서 검토. 개별 인허가 전에 서울시 도시관리과와 사전 협의가 필요하다. **관할 기관 확인.**
- 54~55쪽: 최고높이의 **1.3배 이내**이며 협의 대상이다. 건폐율 완화와 높이 완화를 원칙적으로 중복하지 않는다(기존 모텔의 대상 시설 전환 시 협의 예외). 최대개발규모 별도 조건, 동선지구중심의 불허용도 변경도 별도다. 이 값을 동별 건축 가능 면적으로 환산하지 않는다.
- [2026-264호 정정고시 (2026-05-14)](https://www.jongno.go.kr/dosi/rest/dst/download/propel/1091): 예컨대 광희동 및 효제1·2·3은 기존 지정계획과 중첩되는 **소단위관리지구**에 한한다. 본 층은 2월 고시의 이력이며, 최신 모든 개별 변경을 반영한 허가 지도가 아니다.

## 출처표시·재배포·갱신

- 지자체의 고시 자체는 [저작권법 제7조 제2호](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029423769)상 보호 대상에서 제외되며 조례는 제1호다. AMO는 출처를 밝힌 명칭·기한·대표지번 등의 사실 및 자체 요약만 배포한다. 토지이음의 일반 공공누리 안내만으로 **첨부 도면 속 제3자 기초지도까지 허락받았다고 보지 않는다**. 원본 PDF·도면·경계 복제/벡터화 없이 원문으로 연결한다.
- OA-12857는 해당 페이지 표시 **공공누리 제1유형**(출처표시, 상업 이용·변경 허용). 서울특별시 자료에서 AMO가 지정 명칭·날짜를 정리. 주소 DB는 행정안전부 [공공데이터포털 주소 DB](https://www.data.go.kr/data/15050417/fileData.do) ‘이용허락범위 제한 없음’. 서울만 선택하고 명시 지번의 행정코드를 확인했다. 도로명, 건물명, 점유자, 업소나 원장 전량은 배포하지 않는다. 기존 경계 코드 출처는 [기존 표시](ATTRIBUTION.md) 참고. 도면 자체는 어느 파일도 재배포하지 않는다.
- 신규·정정고시, 조례 개정, 주소 DB·행정경계 개편 또는 기한 경과 시 **수동 재검토**: 서울시보에서 고시번호·기존 계획명·지역별 정정/변경을 검색 → 원문과 부칙·결정도·별도 정비계획 및 현재 유효기간 확인 → 버전과 해시 기록 → 대표지번·행정코드 재대조 → 코드·시보 쪽·결측 테스트 갱신 후 공개. 법적·공간적 적용이 불명확하면 기존 확인 시점을 남기고 새 승인을 표시하지 않는다. 주간 네트워크 수집에 추가하지 않는다. 고시 발표일이나 오늘 날짜만으로 구역을 자동 연장하지 않는다.
- 재현: 위 ZIP의 `rnaddrkor_seoul.txt`를 구조 변경 없이 꺼낸 뒤 `node scripts/strategy/zones.mjs /path/to/rnaddrkor_seoul.txt`. 출처 두 판을 재대조하며 차이가 있으면 실패하고 파일을 덮어쓰지 않는다. API 키·브라우저 쿠키·유료 서비스·외부 질의 발송 불필요.
