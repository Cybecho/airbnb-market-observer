# A1 · 야간 존재인구(00~06시)와 22시

어느 동의 04시 존재인구가 늘었을 때, 야간 구간의 평균도 같은 방향인지 확인하기 위한 보조 지표다. 서울특별시·KT [OA-23018 단기체류외국인 행정동별 생활인구](https://data.seoul.go.kr/dataList/OA-23018/S/1/datasetView.do)의 기존 공개 월 ZIP을 사용한다. 공공누리 제1유형 출처표시. AMO가 시간대와 월 단위로 집계했다. 구 단위 OA-23021이나 다른 원천을 붙이지 않는다.

## 월 × 8자리 행정동 필드 사전

| `observatory.presence.rows` | 단위 | 분자와 분모 |
|---|---|---|
| `meanNight` | 명 | 같은 달력일(KST)의 00, 01, 02, 03, 04, 05, 06시 합 / **7**. 유효한 일평균들의 합 / `daysNight` |
| `daysNight` | 일 | 일곱 슬롯 모두 수치인 날짜 수. 부분적으로 관측된 날은 제외 |
| `mean22` | 명 | 22시 수치 합 / `days22`; 다음 날 새벽과 합치지 않음 |
| `days22` | 일 | 22시가 수치인 날짜 수 |

`quality.refreshMonths[월].validNight`와 `valid22`는 각 월의 동별 유효일 수 합(동·일)이다. 분모가 0이면 평균은 `null`; 원천 수치가 명시적으로 0인 경우만 0으로 센다. 평균은 월 단위에서만 소수 둘째 자리로 반올림한다. `*`는 구조적으로 있는 행이지만 값은 비공개다. 24시간 구조 행 자체가 하나라도 빠지거나 중복되면 그 달을 불완전한 원본으로 보고 실행을 중단한다. 원본 국적별 행·시간별 원자료·사람 식별자는 배포하지 않는다. 기존 04시·14시·평일·주말·유효일·기간 비교 필드는 그대로다. 새 두 계열에는 요일별 분해가 없다.

월별 공통 관측동 비교에는 지표의 유효일이 해당 월 달력일과 같은 동만 사용한다. 동 수는 매달 원본의 서로 다른 코드 수다. 2024-11~2025-07은 426동, 2025-08~2026-10은 427동으로 24개월 10,239행이다. 경계 변경 전후를 현재 코드로 고쳐 쓰거나 없는 동을 0명으로 채우지 않는다. 22시, 04시, 야간 평균은 중복 관측이 가능하여 더하지 않는다. 숙박객, 예약, 숙박일수, 플랫폼 수요의 증가율이 아니다.

## 이미 공개된 판본만 재집계하는 방법

**로컬 실행 금지.** PR의 GitHub-hosted Ubuntu, Node 24, `unzip`, `iconv` 환경에서 실행한다. 다른 8종 수집, npm 의존성, 토큰, 쿠키, API 키가 필요하지 않다. 공식 파일 목록에서 확인한 ZIP만 요청한다. 기존 데이터와 다른 판본을 발견하면 임의로 새 수치로 교체하지 않고 실패한다. 최초 공표 범위의 모든 달이 있는지, 월별 목록판·파일명·ZIP SHA-256, 경계 해시, 기존 공개 파일의 빌드 매니페스트 SHA를 검사한다. 같은 판본의 구조와 월별 코드 집합을 재확인하고 04/14, 구·동 명칭, 유효일, 품질, 기간 파생값, 기존 시각·다른 원천 상태가 바뀌지 않았는지 비교한다. 이력·원천 확인시각을 새로 꾸미지 않는다.

```bash
set -euo pipefail
node scripts/materialize-night-presence.mjs
out="$RUNNER_TEMP/a1-materialized"
# 이 지점까지 저장소에는 아무것도 쓰지 않는다. ZIP/디코딩 데이터는 공개하거나 업로드하지 않는다.
cp "$out/observatory.json" "$out/refresh-state.json" data/organized/insights/
cp "$out/ihwa.md" docs/data/NIGHT-PRESENCE-RESULTS.md
npm run data:build
cmp "$out/observatory.json" public/data/observatory.json
npm run data:check
# 이어서 타입·단위·빌드·공개 검사·브라우저 검사. 실패하면 커밋/배포하지 않는다.
```

`lineage.json`(같은 임시 디렉터리)은 월별 ZIP SHA, 기본·결과 집계 SHA, 월별 코드 수, 실제 재처리 월을 기록한다. 필요할 때 이 파일과 비교문만 검증 증빙으로 사용한다. 일반 주간 수집은 새 필드 또는 품질 카운터가 없는 구 판본을 한 번 재집계한 뒤, 기존의 최신 두 달·신규·목록 정정분 처리로 돌아간다. 공개 판본 고정 재집계는 최신 월을 추가하거나 원천 전체를 확인한 것으로 표시하지 않는다.

## 이화동 판독 기준

행정동 `11110640`의 2026년 1월→2월, 2월→3월 변화 방향·명 차이·증감률을 04시와 야간 평균에서 **각각** 보고한다. 4월은 상승 지속 또는 반전 여부를 읽는 참고월이다. 기준값 0이면 비율을 계산하지 않고, 해당 계열의 어느 한 달이라도 불완전하면 비교를 유보한다. 위 명령이 원본과 SHA 일치를 확인한 뒤 생성한 `ihwa.md`가 정량 결과다. 기존 공개 04시 참조값은 1월 327.66명, 2월 800.00명, 3월 1,485.74명, 4월 1,654.44명이다. 이 값만으로 야간 평균의 크기·상승·원인을 추정하지 않는다.
