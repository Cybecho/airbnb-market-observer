# 월별 숙박 인허가 추세

**질문:** 선택한 업종의 인허가가 이 지역에서 매월 얼마나 늘거나 줄었고, 같은 달 서울 전체는 어땠나? [등록 공급](https://cybecho.github.io/airbnb-market-observer/#view=supply) 또는 기회 화면의 **월별 숙박 인허가 추세**를 사용한다. 지도 동을 클릭해도 같은 선택이 적용된다. 지역 비교에는 같은 업종의 서울 전체가 남는다. 객실·Airbnb 매물·예약·생존한 전체 사업체의 수를 나타내지 않는다.

## 출처와 분류

2026-11-19 확인: 4개 원천의 상세 페이지에서 각각 서울특별시 저작권, 공공누리 제1유형(출처표시, 상업 이용·변경 가능)을 확인했다. 제공기관은 도시민박·한옥·관광숙박은 서울시 25개 자치구, 공중위생 숙박업은 서울특별시다. [공공누리 1유형](https://www.kogl.or.kr/info/licenseType1.do). 운영 갱신도 각 페이지의 자료 ID, 저작권자, 제공기관, 허용 유형·변경 가능 문구를 다시 확인한다. AMO가 날짜 집계와 공간결합을 수행했다. 원본 사업장명·주소·연락처·관리번호·개별 위치 및 날짜 목록은 재배포하지 않는다.

## 한 달에 세는 내용

- **신규** = 남아 있는 원장 행의 인허가일이 그 달인 건수. 실제 영업 첫날은 아니다. **폐업** = 폐업 상태·상세 상태와 명시적인 폐업일이 일치한 기록 건수. 행정취소·직권말소, 휴업, 최종수정일, 파일 갱신일은 폐업으로 치지 않는다. **순증감** = 신규 − 폐업. 취소는 이 차감식에 들어가지 않으므로 순증감과 실제 영업 재고의 변동은 다를 수 있다.
- **월초 등록 중 폐업률(재구성 지표)** = 월초 전날까지 인허가가 존속한 것으로 날짜·상태가 확인되는 등록 중 당월 폐업 건수 ÷ 해당 월초 판정 가능 등록 건수 × 100. 폐업이 월 1일이면 전월 말 분모에는 포함한다. 당월 신규 후 당월 폐업은 신규와 폐업 건수 양쪽에 포함되나 이 비율의 분자·분모에는 들어가지 않는다. 판정된 취소는 등록 집단에서 제외하지만 폐업 사건으로 세지 않는다. 휴업 중인 경우도 등록 효력과 실제 영업 여부는 다르다. 무일자 종료, 불가능한 날짜·상태 충돌, 불명확한 재개업 행은 해당 분모에서 제외한다.
- 현재 남은 원장의 현재 업종·위치로 과거 날짜를 다시 묶은 **소급 집계**다. 각 월말에 실제 조사한 영업점 재고나 공식 폐업률이 아니다. 삭제·정정·이전·업종 전환 이력을 복원하지 못하며, 갱신하면 지난달 값도 달라질 수 있다. 관측 원장 수·코호트 제외 수·공간 연결 수는 JSON의 `sources[].qa`, `qa.byArea`에 남는다. 희소한 곳의 백분율은 분자·분모를 반드시 함께 읽는다.
- 분모 0·미관측·폐업일 미제공은 ‘산출 불가’. 해당 지역·업종에서 한 번도 확인된 원장 행이 없으면 일괄 0으로 채우지 않는다. 확인된 모집단에서 사건이 없었던 완결 월의 건수 0 및 양수 분모의 폐업 0%는 유지한다. 종료 상태에 날짜가 전혀 없거나 심하게 누락된 집단의 폐업은 보류한다. 상위 범위가 보류되면 하위 범위도 보류한다.

## 지리와 기간

서울 전체는 서울시 4개 해당 원장을 각각 센다. 25개 구는 서울이 명시된 주소에서 구를 확인하거나 확인된 행정동 위치를 사용한다. 두 서울 주소가 서로 다른 구면 구/동에 배분하지 않는다. 주소와 공간결합 구가 다르면 확인된 주소의 구에만 남기고 동은 배분하지 않는다. 427개 **8자리 행정동**은 원장 평면좌표를 EPSG:5174에서 CRS84로 변환해 2026-10-01의 검증된 경계 내부 한 곳에만 배정한다([통계청 SGIS](https://sgis.kostat.go.kr), [vuski/admdongkor CC BY 4.0](https://github.com/vuski/admdongkor)). 법정동명으로 나누지 않는다. 서울에는 구·동 미배정 행도 남으므로 하위지역을 더해 서울 합계를 대신할 수 없다.

수집일(한국시간)의 진행 중인 달을 제외하고, 가장 늦게 따라오는 원천의 페이지 데이터 갱신일에서 공시 지연 3일을 뺀 날까지 **월말이 지난 최근 24개월**만 집계한다. 주간 9원천 중 기존 네 인허가 CSV **동일 바이트**를 이용한다. 이 그래프 때문에 추가 권한·가입·API 키·네트워크 호출이 필요하지 않다. 기존 주간 영업 건수 스냅샷과는 별도 지표다.

## 읽기 계약과 재현

`GET supply/v1/monthly.json` (사이트 루트 기준). 스키마 `amo-monthly-permits/1`. `areas.SEOUL`, `areas['구:종로구']`, `areas['11110640']` 같은 범위에서 `series[업종ID][월 인덱스]`를 읽는다. 순서는 **[신규, 폐업, 월초 판정 가능 등록, 그중 당월 폐업]**. 정수 건수 또는 `null`; 비율은 `100 * 4번째 값 / 3번째 값`으로 조건부 계산한다. `months`와 `categories`의 라벨·상위업종·원천을 같이 읽는다. `sources`는 원본 해시·총행 수·실제 판독 범위와 추출 시각의 계보를 제공한다. 날짜를 붙인 폐업과 분자가 같아야 하는 것은 아니다.

[4개 전체 CSV의 열·권리·분류 검산](https://github.com/Cybecho/airbnb-market-observer/actions/runs/44422072483). GitHub-hosted Ubuntu에서만 `node scripts/monthly/review.mjs --collect`; 이 읽기 전용 원본 검산은 러너 임시 디렉터리의 비식별 집계만 산출하고 저장소를 수정하지 않는다. `npm run check:publication`은 공개 파일·열 허용목록, 같은 원천의 상하위·지리 합계와 미배정, 월별 분모·이탈 일관성, 453곳의 신원을 검사한다. 실수·실패 시 기존 배포물을 유지한다.

**판정 규칙:** 모집단이 없거나 인허가일이 하나도 없으면 신규 미제공, 10행 이상에서 날짜가 10% 미만이어도 보류한다. 폐업일 미제공 원천, 종료 행이 있으나 명시 폐업 0행인 범위, 종료 10행 이상 중 무일자 종료 90% 이상인 범위는 폐업을 보류한다. 월초 집단도 위 조건과 판정 가능 행 0건(10행 이상에서는 10% 미만)을 검사한다. 구/서울 또는 상위 업종의 보류 이유가 하위 범위보다 우선한다. 명시적 일시 휴업(02/02)은 등록 자체의 취소가 아니므로 날짜상 존속하는 등록에는 포함될 수 있다. ‘영업 중’으로 해석하지 않는다. 다른 미검토 상태 조합이 나타나면 갱신을 중단한다.
