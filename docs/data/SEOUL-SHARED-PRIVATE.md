# 서울 공유숙박 월별 지표: 개인 파일로 보기

**자료 연결**, **숙소 성과**, **월별 추세**의 ‘야놀자 CSV 연결’에서 적법하게 확보한 서울 전체 월별 CSV를 선택한다. 서버로 업로드하지 않는다. 한 탭의 메모리에만 두며 파일 연결 해제 또는 새로고침으로 비운다. 파일을 잘못 선택하면 기존 검증 결과를 보존한다. 개인 저장소 최신값을 공개 사이트가 인증 없이 가져오는 기능은 없다. 자동 점검 차트는 소유자만 인증하여 개인 저장소에서 확인한다.

헤더: `month,adr_krw,occ_pct,revpar_krw,source_file,file_number,file_registered`. 관측월은 YYYYMM, 금액은 원, OCC는 0~100 퍼센트다. 파일 날짜는 통계의 발행일·집계일로 쓰지 않는다. 결측·누락월은 0으로 메우지 않는다. RevPAR은 독립 수록 열로 유지하며 ADR×OCC로 계산하지 않는다. 도시 전체의 공유숙박 시장으로만 읽고 자치구·행정동, 특정 플랫폼의 예약·정산 또는 개별 수익률로 환산하지 않는다.

이 저장소의 main·Pages·공개 테스트에 실제 CSV·차트나 원문 다운로드 코드를 넣지 않는다. 수집·배포 허가가 없는 원사이트에 요청하지 않는다. 공개 앱 검사는 가상 수치로 실행하고 실제 파일은 기기에서만 확인한다. 기존 인허가·지도 데이터와 독립적이다.
