* [다른 연속지적도 제품 dsId=30563](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?dsId=30563)는 실제 공급처가 **CC BY-NC-ND**로 표시한다. 같은 정부 포털·같은 주제여도 dsId=23의 허가를 옮기지 않는다. [OA-15551](https://data.seoul.go.kr/dataList/OA-15551/S/1/datasetView.do)은 연도별 시군구 단위라 제외한다.
* [국토교통부 개별공시지가정보 WMS/WFS/속성정보, 15124014](https://www.data.go.kr/data/15124014/openapi.do) 및 [공식 안내](https://www.vworld.kr/dtna/dtna_guide_s001.do): 무료, 개발 자동승인·운영 심의, 서비스 인증키·기관별 호출량 정책. WFS만 벡터 후보이며 WMS 그림/속성 조회만으로는 안 된다. **구현에서 호출·키 등록·과금 없음**. 수량·저장·재배포·도메인 조건을 확인하고 소유자가 이 서비스에 대해 승인해야 검토 가능하다.
* 가장 작은 다음 단계: dsId=23의 지정된 **서울 전체 1월 SHP**를 허가된 계정으로 확보하여 안전한 러너 비공개 입력으로 제공하고, 전송 전 SHA256을 별도 기록한다. 인증정보 공유·키·유료서비스는 불필요하다. 그 전에는 공개 `land.json` 파일도, 동별 숫자도 없다.

## 실행 · 산출 계약

1. GitHub-hosted Ubuntu에서만 `node scripts/strategy/land-source.mjs`: 공개 서울 자료 페이지의 다운로드 폼을 검증한 뒤 해당 파일만 익명 POST. 인증정보/쿠키 없음. ZIP 크기·멤버수·해제 크기·CRC·SHA256 검사. 원본은 메모리에서 소멸한다.
2. 위 지정 SHP를 러너의 **체크아웃 바깥** `$RUNNER_TEMP/land-vworld-23-4258.zip`에만 임시 전달. 승인을 받은 반입 경로가 없으면 중단하고 Git/Actions artifact/cache/log/외부 공유 URL을 사용하지 않는다. `command -v ogrinfo ogr2ogr gdalsrsinfo unzip zipinfo iconv` 및 `ogrinfo --version`으로 기존 환경 확인. GDAL 3.7+ (`ogrinfo -json`), SQLite/GEOS, PROJ EPSG 데이터가 필요하다. `node scripts/strategy/land-collect.mjs`는 도구가 없거나 파일·포맷이 다르면 설치나 허용범위 확대 없이 중단한다. 원천 수집이 아니므로 `npm test`의 오프라인 합성 테스트는 네트워크·GIS 불필요.
3. CSV `기준년도/기준년월=2026-01` 고정. 토지코드와 10자리 법정동코드 + 필지구분(일반1/임야2) + 본번(4) + 부번(4)을 **문자열로** 대조한다. 이름은 읽지 않는다. 해당 필지 `.dbf` A1과 일치해야 하며 A2와 접두부도 검증한다. 기타 지번은 원인을 계수하고 잘못된 19자리로 만들지 않는다. 동일 기간 중복 PNU/도형 PNU, 코드 불일치는 중단한다. 이후 월, 미확인 가격, 대상 원장에 없는 지적 필지는 별도 계수한다.
4. 실제 `.prj` EPSG:5186 검증 → 단일·다중 지적 폴리곤의 **투영 평면 면적 중심점** → 자기 필지 내부 확인 → CRS84 변환 → 427개 행정동 폴리곤의 배타적 내부점 검사(구멍 포함). 경계선·중복 내부·외부·무효 도형·내부 밖 중심점·미매칭 원장 필지는 분리 계수한다. 가장 가까운 동·동명·구별 할당 또는 면적 배분은 없다.
5. 한 대상 PNU 한 표, 원/㎡ 값의 짝수 중앙값은 가운데 두 값 평균. `land.json.candidate`만 runner temp에 생성한다. 자료·경계 해시, 시점, 원자료/매칭/누락 수, 427 `{adminCode, parcelCount, medianKrwPerM2}` 외 필지 식별자·주소·지번·점·개별가격 없음. 최소 동별 30필지, 전 427동, 참조월 80만행 이상, 참조월 원장 대비 배정 ≥99%, 모든 건수 보존이 필요하다. 이는 정확도 보장이 아닌 오류 감지 하한이다. 미매칭 편향과 기준시점 차이, 동 단위 품질, 이용허락, 원본 해시 및 공개 필드목록을 별도 검토 후에만 집계 배포. 변경된 ZIP/경계·키·입력 계약은 새 버전으로 재검토한다. 실패 시 숫자를 만들어 채우지 않는다.
6. `src/LandContext.tsx`는 검증된 파일 SHA256을 명시적으로 등록하기 전에는 요청하지 않는다. 승인된 경우에만 `public/strategy/v1/land.json` 및 `RELEASE_SHA256`을 함께 등록한다. 목록은 조회 대상 동의 코드를 키로 읽으며 04시 지표와 별도 열에 단위를 표시한다. UI 인터페이스: `<LandContext areas={selectedAreas} periodLabel={index.period.current}/>`; 여러 동에서도 행 선택/기존 순위 불변. 기존 [README](README.md), [공개 데이터 계약](CONTRACT.md), [데이터 라이선스](../../DATA_LICENSES.md)에 적용되는 동명/구 배분 금지 및 원장 비공개 원칙을 유지한다.
