# B3 건축물대장: 승인된 키 보관 범위와 제공기관 확인 사항

**결정:** 소유자는 무료 공식 자격증명을 GitHub Actions Secrets에 넣어 별도의 수동 수집에서 쓰는 것을 허용했다. 다시 결정할 사항이 아니다. 기본 설정은 **꺼짐**이다. 이 문서는 자격증명 발급·등록·호출 성공이나 새 공개 관측을 증명하지 않는다.

## 어느 자료를 어떤 조건으로 쓰는가

- 국토교통부 [건축HUB 건축물대장정보 서비스(15134735)](https://www.data.go.kr/data/15134735/openapi.do), [표제부 상세기능 명세](https://www.data.go.kr/en/data/15134735/openapi.do). 2026-11-18 확인. 월간, 무료, 이용허락범위 제한 없음. 개발·운영 모두 자동승인 방식이지만 해당 계정·서비스의 활용신청은 필요하다. 개발계정 신청 가능 트래픽 표시는 10,000이며 우리 호출 한도가 아니다.
- 유일한 HTTPS GET: `https://apis.data.go.kr/1613000/BldRgstHubService/getBrTitleInfo`. 기존 ArchPmsService·구형 서비스·총괄표제부·전유부·층별개요가 아니다. `sigunguCd=11170`, `bjdongCd=11900`, `_type=json`, `numOfRows=100`, `pageNo=1..12`. 서비스키만 서버에서 최종 인코딩한다.
- [포털 robots](https://www.data.go.kr/robots.txt)는 Googlebot의 일부 포털 경로를 제한한다. [API 호스트 robots](https://apis.data.go.kr/robots.txt)는 확인 당시 HTTP 400 XML 응답으로 크롤 규칙을 제공하지 않았다. 포털 페이지 크롤링을 하지 않고 허가된 API 기능만 사용한다. robots 응답은 활용승인 또는 재배포권이 아니다.
- **남은 제공기관 조건:** 공식 포털에서 이 서비스의 현재 승인, 키 유효기간, 이용 목적·무료 잔여량을 확인한다. 과거 승인 기록은 2026-05-22이나 현행 유효성·키 등록 여부는 별도다. 요금이 생기거나 승인·기간이 불분명하면 실행하지 않는다. 익명 테스트·예시키·타인 키를 쓰지 않는다.

## 한 동만, 어떤 수치인가

[서울시 자치구별 관할표](https://www.seoul.go.kr/seoul/autonomy_sub.do)의 용산구 행정동 효창동 관할 법정동은 효창동 한 곳이며 다른 행정동으로 쪼개지지 않는다. 검토한 한 쌍 **법정동 1117011900 → 행정동 11170580**만 허용한다. 요청·응답의 시군구 5자리+법정동 5자리, 저장소 법정동 코드, 2026-10-01의 경계 코드·SHA-256을 검사한다. 지번 문자열에서 이름을 읽거나 주소를 지오코딩하지 않는다. 이 대응 관계를 다른 동에 일반화하지 않는다. 경계 변경/관할 변동 시 재검토한다.

고유 관리대장 PK를 메모리에서만 검사한다. 전체 페이지·행 수·중복 검사를 통과한 **주건축물 일반/집합 표제부**만 대상으로, 단독주택·공동주택·숙박시설·근린생활시설·확인한 기타 용도로 구분한다. 부속건물·총괄·전유행을 더하지 않는다. `mainTitleCount`의 단위는 표제부이고 주택·세대·객실이나 실제 숙박 가능 건물 수가 아니다. `observedGrossAreaM2.value`는 관측된 `totArea`의 합(10㎡ 단위 반올림), `meanAboveGroundFloors.value`는 관측된 `grndFlrCnt` 평균(0.1층), `observed`는 각 지표의 유효 표제부 수다. 관측 누락분은 추정하지 않는다. 원천 기준일과 조회일은 구별한다.

유효한 대장이 10건 미만인 셀은 생략하며 작은 셀을 뺄셈으로 복원할 전체 합계는 쓰지 않는다. 면적·층수의 유효 건수가 10 미만, 누락이 1~9건이거나 단일 건 기여도가 80%를 넘으면 해당 지표는 `null`이다. 양수가 아닌 면적·층수는 관측 합이나 평균에 넣지 않는다. 코드 불일치·미매핑 용도·중복 ID·예산 초과·불완전 페이지는 결과 전체를 보류한다. 개별 건축물·필지·주소·건물명·ID는 내보내지 않는다. **관할 기관 확인:** 개별 호의 전용면적, 거주·소방 요건, 실제 허가·영업은 이 집계로 판정할 수 없다.

## 정확한 운영 인터페이스

1. 공개 저장소의 `authorized-spatial` Environment에 배포 브랜치를 `main`으로 제한한다. 후보 Secret 이름은 **`DATA_GO_KR_SERVICE_KEY`**(공식 디코딩 키). URL, 쿠키, PAT, `.env`, `VITE_` 또는 사용자 입력으로 전달하지 않는다. 제공기관 확인 후 같은 Environment에 비밀이 아닌 `BUILDINGS_APPROVAL_REFERENCE`(승인 기록 참조번호, 영숫자·`.`·`_`·`-`, 3~80자), `BUILDINGS_REVIEW_UNTIL`(UTC `YYYY-MM-DD`, 실제 만료 이내·최대 90일 재검토)을 둔다. 참고번호에 개인 식별 정보는 넣지 않는다. 이 값들은 자동승인을 만들어내는 스위치가 아니다.
2. 신뢰된 `main`의 `authorized-spatial.yml`에 `workflow_dispatch(provider=buildings)`. 선택지 `off`가 기본. 정규 빌드·PR·주간 갱신에는 키·환경변수·네트워크 의존을 추가하지 않는다. 동시 한 작업, 재실행 금지, 표준 무료 Linux 러너 5분, 최대 **12회/1,200행**, 응답당 3 MiB/10초·재시도 없음. `https` 고정 호스트에서만 요청하고 리다이렉트를 따르지 않는다. 전용 수집 단계에만 키를 넘긴다.
3. 성공 결과는 공개될 수 있는 **수동 Actions 요약의 허용 집계**에서만 검토한다. 원문 파일·URL 로그·artifact·커밋·Pages 게시 없음. `schema=spatial-review/1`, `provider=molit-title`; 주간 이력이나 기존 시세·인허가 건수와 합산하지 않는다. 실패하면 요약 수치가 없다. 노출 의심 시 즉시 키 폐기/교체 및 기존 로그 삭제, 확인 완료까지 비활성 유지.
