# Airbnb Market Observer

서울 25구, 427개 행정동, 467개 법정동의 숙박시장 근거를 지도·표·데이터 계보로 비교하는 독립 연구 프로젝트입니다. Airbnb와 제휴 또는 보증 관계가 없습니다.

> 데이터는 2026-11-15까지 수집한 스냅샷입니다. 배포 자동화는 원천 데이터의 실시간 갱신을 뜻하지 않습니다. 여관 카드추정매출, 월세 계약, 관광객 설문, 통신 기반 존재 추정과 인허가는 서로 다른 측정값입니다. 실제 Airbnb 정산 매출이나 투자 수익률로 합치지 않습니다.

현재 공개판을 구성하고 있습니다. 원자료 권리 확인이 완료된 범위만 게시하며, 전체 조사 범위와 제외 사유도 문서화합니다. 최종 배포 안내와 실행 절차는 구축 완료 시 함께 갱신합니다.
